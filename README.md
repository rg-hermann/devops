# DevOps Portfolio

Bem-vindo ao meu portfólio de projetos e automações DevOps! Este repositório reúne soluções que desenvolvi para gerenciar infraestrutura como código (IaC), automações e pipelines CI/CD. O objetivo é demonstrar o uso de tecnologias modernas para criar ambientes escaláveis, seguros e automatizados na nuvem.

---

## 📋 Visão Geral

Este portfólio abrange:

- **Infraestrutura como Código (IaC)**: Provisionamento e gerenciamento de recursos na nuvem usando Terraform.
- **Automação**: Scripts em Bash e Python para tarefas repetitivas e provisionamento de infraestrutura.
- **Pipelines CI/CD**: Automação de deploys e integração contínua com ferramentas como Azure DevOps e GitHub Actions.
- **Cloud Computing**: Utilização de serviços AWS, como S3, ECS, Lambda, RDS, entre outros.

---

## 🔒 Segurança

Para proteger variáveis sensíveis, utilizei **Git-Crypt** com a chave `devops.asc`. Essa abordagem garante que informações confidenciais sejam mantidas seguras, mesmo em projetos de demonstração.

## ⚙️ Automação

### Scripts em Bash e Python 🐍
Automatizações para provisionamento de recursos e execução de tarefas comuns no ambiente DevOps, incluindo:

- Deploy de aplicações
- Configuração de ambientes
- Integração com pipelines CI/CD
- Gerenciamento de recursos na AWS e Azure

---

## 🚀 Tecnologias Utilizadas

Este portfólio faz uso das seguintes tecnologias e ferramentas:

- **Terraform**: Provisionamento de infraestrutura como código.
- **AWS**: Serviços como S3, ECS, Lambda, RDS, SQS, API Gateway, entre outros.
- **Azure**: Gerenciamento de recursos como VMs, Function Apps e SQL Databases.
- **Bash e Python**: Scripts para automação e integração.
- **CI/CD**: Pipelines para deploy e integração contínua usando Azure DevOps, GitHub Actions e CircleCI.

---

## 📂 Estrutura do Repositório

- **`terraform/`**: Configurações de infraestrutura como código.
- **`ansible/`**: Playbooks para automação de configuração de servidores.
- **`python/`**: Scripts em Python para integração com AWS e Azure.
- **`bash/`**: Scripts em Bash para automação de tarefas.
- **`.github/workflows/`**: Pipelines CI/CD usando GitHub Actions.
- **`.azure/`**: Templates para pipelines no Azure DevOps.
